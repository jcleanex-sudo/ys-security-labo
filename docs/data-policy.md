# データ利用方針

確認日: 2026-08-04

## 初期版の結論

- JRA公式ページを巡回するスクレイパーは実装しない。
- 出走表、オッズ、結果は「利用許諾済みの契約データ」または「権利を確認した手入力ファイル」だけを受け付ける。
- 出所、利用条件、取得時刻、完全性のいずれかが確認できなければ `DATA BLOCKED` とする。
- 馬名、オッズ、結果、欠損値を推測で補わない。
- サイト上でJRAのロゴ、写真、映像、記事本文を再利用しない。

## 公式情報の確認結果

JRAの「ご利用に際して」は、JRAが管理するインターネットメディア上の映像・音声・画像・記事等がJRAまたは第三者の著作物であり、所定範囲を超える二次利用には事前許諾が必要と説明している。

- https://www.jra.go.jp/use/

JRAはJRA-VANを、出馬表、リアルタイムオッズ等を提供するJRA公式データ配信サービス（有料）として案内している。

- https://www.jra.go.jp/link/eizo.html

JRA-VAN Data LabのSDK資料は、JV-Linkを通して競馬ソフトへデータを取り込む仕組みを示している。ただし、公開Webサイトでのデータ再配信可否はSDKの技術説明だけでは確定できない。契約条項とソフト登録・表示範囲をJRA-VANへ確認するまで本番接続しない。

- https://jra-van.jp/dlb/sdv/sdk/DataLab422.pdf
- https://jra-van.jp/dlb/sdv/soft_reg.html

## データ導入時の承認チェック

1. 契約者と利用目的が契約範囲内である。
2. GitHub Pagesで公衆送信してよいフィールドが明文化されている。
3. 過去データの保存期間と再配信範囲が確認できる。
4. オッズ更新頻度、キャッシュ、アクセス上限を守れる。
5. 出所表示、商標表示、削除要請への対応を実装できる。
6. 確認記録を残し、`source_terms_confirmed` を人が `true` に変更する。

この確認は法的助言ではない。公開前に権利者の最新規約と回答を再確認する。
